# Manifest overview

The manifest is a strict YAML document with four top-level sections:

```yaml
version: 1
name: my-lab
topology:
  nodes: {}
  links: []
```

Use the topic pages below when writing a topology:

- [Nodes and interfaces](manifest-nodes.md)
- [Routing and node policy](manifest-routing.md)
- [Links and link conditions](manifest-links.md)
- [Qdisc configuration](manifest-qdisc.md)
- [Complete field reference](manifest.md)

The complete reference remains available as a compatibility entry point for existing links.
